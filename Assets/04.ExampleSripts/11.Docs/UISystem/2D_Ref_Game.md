# 데이브 더 다이브(2D게임) 의 3가지 핵심 기능

- 1. 첫번째 낮시간 다이빙으로 바다 탐험 및 물고기 수집
  - 낮에는 '블루홀' 이라는 해양 맵에서 물고기를 잡고
  무기재료, 광물, 유물등을 챙길수있다.
 탐험과정에서 체력대신 산소시스템(o²)와 무게제한으로
 해당 리스크 안에서 얼만큼 깊은곳에서 재료를 수집하느냐에 따라
 매장의 수입차이가 커진다 하지만 그만큼 깊은곳에서의 위험이 노출되어
  유저가 사망할시 수집해왔던 재료들을 상당수 잃게되므로 
  플레이어의 리스크관리가 매우중요          
       
- 2. 두번째 밤시간 스시 레스토랑 운영
  - 낮에 수집해온 재료들로 손님들에게 초밥을 제공해주므로서
  수입을 올릴수있다.
  메뉴 선택 시스템으로 어떤재료의 음식을 만들지 정해서 최대한
  많은 이윤을 남기는것이 중요하다.
  본인이 직접 서빙액션(음식 서빙, 청소등...)을 하거나 
  아르바이트를 고용해서 자동화 시스템으로 가게를 운영하는것도 가능하다
  아르바이트생은 교육으로 스탯업을 시키거나 
  요리재료수급을 위한 파밍용으로 사용이 가능하다. 
  
- 3. 플레이어의 성장 및 업그레이드 그리고 스토리 파트
    - 돈 과 재료(무기강화에 필요한)가 모이면
  그걸로 산소통(Hp역할), 무기(작살총, 총), 잠수복(수심 제한), 가방(무게제한) 같은걸 업그레이드하여
  더깊은곳에서 더오랫동안 더위험한 물고기나 재료들을 수급할수있게됩니다.
  장비를 업그레이드할수록 더 비싸고 좋은 재료들을 수급할수있기에 유저에게 동기부여를 해주게됩니다.
  또한 반복노가다로 지루할수있는 부분을 자연스럽게 스토리 진행과 서브 이벤트 or 미니게임들이
  이러한 부분들을 완화하고 게임을 더 재밌게 해줍니다.

|:-------------------------|:-------------------------------------------------:|:------------------------------------------------------------------:|

| 3.성장 및 업그레이드 & 스토리       |             장비·무기·식당·메뉴 업그레이드, 퀘스트 진행             |            잠수·식당 루프를 점점 강하게 만드는 메타 진행, 컨텐츠 해금, 반복 피로 감소            |

## 데이브더 다이브의 기능 추출

 - 1. 낮시간 잠수의 기능들 
 1. 물속에서 잠수하고있을때 지속적으로 산소통이소모되는 기능 
2. 작살총(무기)로 물고기를 맞췄을때 힘겨루기로 물고기를 수집하는 기능 
3. 물속에서 다양한오브젝트와의 상호작용을 통한 요리재료 수급 및 산소통회복 및 잠수속도 증가, 아이템 추가 기능
4. 헤엄칠때 특정키를 누르면 이동속도가 빨라지며 그만큼 산소통 소모가 늘어나는 기능
5. 특정 무기(그물총, 마취총)로 대형 물고기를 잡았을시 잠수정을 소환해서 안전하게 수집하는 기능
6. 잡은 물고기 및 재료를 표시하는 UI 기능
- 2. 밤시간 스시식당의 기능들
1. 유저가 수급해온 재료들을 확인하는 기능
2. 유저가 직접 수급해온 재료들로 요리를 선택하는 기능
3. 유저가 수급해온 재료를 판매하는 기능
4. 유저가 직접 서빙액션을하여 손님들의 만족도를 상승시키는 기능
5. 만든요리 및 아르바이트생 강화하여 자동화 및 수입증진을 하는기능
6. 낮시간대의 요리재료수급을 아르바이트생에게 조달하게 하는 기능
7. 요리사가 손님의 주문을 받으면 메뉴에 선택된 재료들을가지고 요리를 생산하는 기능

- 3. 그외의 기능들
1. 장비(산소통, 가방, 작살총 및 총등...)을 수급해온 재료들 및 돈으로 업그레이드 하는기능
2. 특정 장소에 가면 서브 퀘스트가 활성화 되는기능
3. 해금된 장소에 따라 낮시간에 잠수시 원하는 위치를 선택하여 그위치까지 직접 이동시켜주는 기능
4. 낮시간 또는 밤시간에 시간의 흐름에따라 메인퀘스트가 진행되는 기능
5. 휴대폰UI로 미니게임 및 서브퀘스트를 진행하게 하고 그에따른 보상을 받는 기능
6. 수집한 재료들을 직접 키워내는 양식장 및 농장기능
7. 아르바이트생들로 서브점 가게를 만드는 기능
8. 식당을 좀더 멋지게 꾸밀수있게 해주는 기능
9. 휴대폰 및 보트를 꾸밀수있게 해주는 기능
