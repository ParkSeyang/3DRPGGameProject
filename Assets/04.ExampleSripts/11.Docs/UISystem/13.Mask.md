# 특정 영역만 보여주는, Mask

## Mask란 무엇인가?

창문 밖의 풍경을 상상해봅시다. 우리는 창문이라는 '틀'을 통해서만 바깥 풍경의 '일부분'을 볼 수 있습니다. 창틀에 가려진 나머지 풍경은 존재하지만 우리 눈에는 보이지 않습니다.

UI에서 **Mask(마스크)** 는 바로 이 '창틀'과 같은 역할을 합니다. `Mask` 컴포넌트가 적용된 UI 요소는, 자신의 자식 요소들 중에서 자신의 사각 영역을 벗어나는 부분을 화면에 그리지 않고 '잘라내는(clipping)' 기능을 합니다.

정의하자면, `Mask`는 자식 그래픽 요소들이 자신의 `RectTransform` 영역 내부에 있는 부분만 렌더링되도록 제한하는 컴포넌트입니다. 프로필 사진을 동그란 모양으로 보여주거나, `Scroll View`에서 스크롤 영역을 벗어나는 콘텐츠를 가리는 등 UI 디자인을 깔끔하게 만들고 특정 형태를 표현하는 데 매우 유용하게 사용됩니다.

## 핵심 요약

-   Mask는 **자신(부모)의 영역을 벗어나는 자식 UI 요소들을 보이지 않게** 잘라내는 컴포G넌트입니다.
-   기본 `Mask`는 사각형 형태로 자르며, `Image` 컴포넌트와 함께 사용됩니다.
-   **Rect Mask 2D**는 사각형 형태로만 자르지만, 복잡한 계산이 없어 `Mask`보다 훨씬 성능이 좋습니다.
-   `Scroll View`의 `Viewport`에서 콘텐츠를 가리는 데 핵심적인 역할을 합니다.

## 세부 개념

### 1. Mask 컴포넌트

가장 기본적이고 유연한 마스크입니다. `Image` 컴포넌트와 함께 사용되며, `Image`의 알파(alpha) 채널을 기준으로 마스킹을 수행합니다.

**Public Field**

| 항목 | 설명 |
| :--- | :--- |
| `Show Mask Graphic` | `true`이면 마스크 역할을 하는 `Image` 그래픽 자체를 화면에 표시합니다. `false`이면 마스크 `Image`는 보이지 않고 오직 자식들을 잘라내는 기능만 수행합니다. |

-   **작동 원리**: `Mask` 컴포넌트는 GPU의 스텐실 버퍼(Stencil Buffer)라는 기능을 사용합니다.
    1.  `Mask`의 `Image`를 먼저 그리면서 스텐실 버퍼에 '구멍'을 뚫습니다.
    2.  그 자식 요소들을 그릴 때, 스텐실 버퍼에 뚫린 구멍 부분에만 그리도록 GPU에 명령합니다.
-   **장점**: `Image`의 스프라이트 모양에 따라 **사각형이 아닌 원형, 별 모양 등 자유로운 형태로 마스킹**이 가능합니다. 프로필 사진을 동그랗게 자르는 것이 대표적인 예시입니다.
-   **단점**: 스텐실 버퍼를 사용하는 것은 렌더링 파이프라인에 추가적인 단계를 요구하므로, 여러 개 중첩해서 사용하면 성능에 부담을 줄 수 있습니다.

### 2. Rect Mask 2D 컴포넌트

이름에서 알 수 있듯이, 오직 **단순한 사각형 형태**로만 자식들을 잘라냅니다.

-   **작동 원리**: GPU의 복잡한 기능을 사용하는 대신, CPU에서 자식 요소들의 `RectTransform`이 자신의 영역과 겹치는지 수학적으로 계산하여 렌더링 여부를 결정합니다.
-   **장점**: `Mask` 컴포넌트에 비해 계산 비용이 훨씬 저렴하여 **성능이 매우 좋습니다.** UI 요소가 많고 복잡한 `Scroll View`처럼 사각 형태의 마스킹만 필요한 경우에는 `Rect Mask 2D`를 사용하는 것이 압도적으로 유리합니다.
-   **단점**: 원형 등 비정형 마스킹은 불가능합니다.

## 개념 다이어그램 & 코드 예제

`Mask`는 시각적 표현을 위한 컴포넌트이므로, 스크립트로 직접 제어하는 경우는 드뭅니다. 아래는 구조에 대한 다이어그램입니다.

```text
[계층 구조 예시: 원형 프로필 사진]

└── 🖼️ ProfileMask (Image, Mask)  <- 1. 부모 오브젝트
    │   - Image Source: 원형 스프라이트 (가운데는 흰색, 바깥은 투명)
    │   - Mask Component: 활성화
    │
    └── 🖼️ ProfilePicture (Image)   <- 2. 자식 오브젝트
        │   - Image Source: 실제 캐릭터 초상화 스프라이트
        │
        └── (결과: 캐릭터 초상화가 부모의 원형 스프라이트 모양으로 잘려서 보임)
```

```text
[계층 구조 예시: Scroll View]

└── 📜 ScrollView
    └── 🖼️ Viewport (Image, Rect Mask 2D) <- 1. Viewport에 Rect Mask 2D 적용
        │
        └── 📄 Content (Vertical Layout Group) <- 2. Content 패널
            │
            ├── 🔘 Item 1
            ├── 🔘 Item 2
            └── ... (많은 아이템들)
            
            (결과: Content 패널의 아이템들은 Viewport의 사각 영역을 벗어나면 보이지 않음)
```

## 활용 예시

### 예시 1: 원형 프로필 사진 만들기

1.  `UI -> Image`를 생성하고 `ProfileMask`라고 이름 짓습니다.
2.  `ProfileMask`에 `Component -> Rendering -> Mask` 컴포넌트를 추가합니다.
3.  `ProfileMask`의 `Image` 컴포넌트의 `Source Image`에 가운데가 채워진 원형 스프라이트를 할당합니다.
4.  `ProfileMask`의 자식으로 `UI -> Image`를 하나 더 생성하고 `ProfilePicture`라고 이름 짓습니다.
5.  `ProfilePicture`의 `RectTransform` 크기를 `ProfileMask`보다 약간 더 크게 조절합니다.
6.  `ProfilePicture`의 `Source Image`에 실제 사용할 캐릭터 초상화 이미지를 할당합니다.
7.  게임을 실행하면, `ProfilePicture`가 부모인 `ProfileMask`의 원형 모양에 맞춰 동그랗게 잘려 보이는 것을 확인할 수 있습니다.

### 예시 2: `Scroll View`에서의 역할

`UI -> Scroll View`를 생성하면, 기본적으로 `Viewport` 게임 오브젝트에 `Rect Mask 2D` 컴포넌트가 이미 적용되어 있습니다. 이것이 `Scroll View`의 핵심 원리 중 하나입니다. `Content` 패널이 아무리 길어져도, 사용자는 `Viewport`라는 사각형 '창문'을 통해서만 그 내용을 볼 수 있습니다.

## Note: 주의사항

-   **`Mask`와 `Rect Mask 2D`의 차이**: 성능이 중요한 `Scroll View`나 단순 사각 클리핑에는 `Rect Mask 2D`를, 원형 프로필 사진처럼 비정형 마스킹이 필요할 때는 `Mask`를 사용하는 것이 좋습니다.
-   **중첩 마스크와 성능**: `Mask` 컴포넌트는 중첩될수록 성능 부하가 기하급수적으로 늘어날 수 있습니다. 복잡한 UI에서 마스크를 여러 겹으로 사용하는 것은 피해야 합니다.
-   **마스크와 자식 요소**: `Mask`는 오직 자신의 **자식(Children)** 들에게만 영향을 줍니다. 형제(Sibling)나 다른 계층의 오브젝트는 마스킹할 수 없습니다.
-   **`Show Mask Graphic`**: `Mask` 컴포넌트의 `Show Mask Graphic` 옵션을 끄면, 마스크의 `Image`는 렌더링되지 않아 `Draw Call`을 하나 줄일 수 있습니다. 마스크의 형태만 필요하고 배경 이미지는 필요 없을 때 유용합니다.

## Further Study: 확장 학습

-   **셰이더 기반 마스킹 (Shader-based Masking)**: `Mask` 컴포넌트를 사용하지 않고, 커스텀 셰이더를 작성하여 마스킹 효과를 구현할 수 있습니다. 이는 GPU에서 모든 계산이 이루어지므로 매우 빠르며, 부드러운 가장자리(Soft-edge) 처리 등 `Mask` 컴포넌트로는 불가능한 고급 효과를 만들 수 있습니다.
-   **Sprite Mask**: UGUI가 아닌 2D 스프라이트 렌더러(Sprite Renderer)를 위한 마스킹 컴포넌트입니다. 월드 공간에 있는 스프라이트에 마스크를 적용하고 싶을 때 사용합니다.
-   **스텐실 버퍼 (Stencil Buffer)**: `Mask` 컴포넌트의 작동 원리인 스텐실 버퍼에 대해 깊이 학습하면, 마스킹뿐만 아니라 포탈(Portal) 효과, 특정 오브젝트만 렌더링하지 않기 등 다양한 고급 렌더링 기법을 이해하고 구현하는 데 큰 도움이 됩니다.
